# tools/dadata — сведения о компаниях, банках, судах и налоговых инспекциях (DaData)

CLI-клиент API [DaData](https://dadata.ru/api/) для справочных сведений: реквизиты и состояние компании или ИП по
ИНН/ОГРН, поиск по названию, филиалы, банки по БИК, справочники судов и налоговых инспекций, карточка контрагента в
markdown и блок реквизитов для договора. Вывод — JSON.

**Статус: рабочий, проверен вживую на бесплатном тарифе** (все команды, кеш, ошибки). Поля платных тарифов разбираются
кодом, но на живом платном ключе не проверялись.

Это один из источников сведений о компаниях, не единственный: выбирает источник агент по задаче. Для суда и сделки
нужна выписка ЕГРЮЛ/ЕГРИП на дату, а не карточка DaData; дел, подробностей банкротства и исполнительных производств
у DaData нет (см. [Чего нет](#чего-нет-у-dadata)).

## Требования и ключ

- Python 3.9+, `pip install -r tools/dadata/requirements.txt` (только `requests`). Запуск: `python -X utf8 tools/dadata/dadata.py ...`
- Ключ даёт пользователь (личный кабинет dadata.ru; регистрацию, подтверждение почты и принятие оферты делает он сам). Хранится в
  `secrets/dadata.json`, закрытом `.gitignore`; можно передать и переменной `DADATA_API_KEY` (она главнее файла). Ключ
  не печатается ни в выводе, ни в ошибках, ни в кеше.
- Сохранить ключ: `printf '%s' "<ключ>" | python -X utf8 tools/dadata/dadata.py auth set --stdin`. Если пользователь вводит ключ
  сам, достаточно `auth set` (запрос в терминале, ввод виден). Неверный ключ (401) не сохраняется. Сразу определяется тариф.
- Секретный ключ DaData не нужен: он требуется только для платной «Стандартизации».

## Быстрый старт

```
python -X utf8 tools/dadata/dadata.py --pretty company --query 7707083893
python -X utf8 tools/dadata/dadata.py report --query 7721581040
python -X utf8 tools/dadata/dadata.py bank --query 044525225
python -X utf8 tools/dadata/dadata.py court --query "арбитражный суд москвы"
```

Глобальные параметры (ставятся перед командой): `--pretty`, `--min-interval` (пауза между запросами, 0,25 с),
`--cache-hours` (срок жизни локального кеша, 24 ч; 0 — без кеша), `--refresh` (не брать из кеша).

## Команды

| Команда | Что делает | Метод DaData |
|---|---|---|
| `auth set\|status\|check\|forget` | сохранить ключ, показать состояние (без ключа), проверить ключ и определить тариф, удалить ключ | `findById/party` |
| `company --query ИНН\|ОГРН\|ИНН/КПП` | реквизиты, статус, руководитель, адрес, ОКВЭД; по умолчанию головная организация (`--all-branches`, `--type`, `--status`, `--raw`) | `findById/party` |
| `find --name "..."` | поиск компании по названию (до 20); базовые поля | `suggest/party` |
| `branches --query ИНН` | филиалы: КПП, статус, адрес | `findById/party` |
| `requisites --query ...` | блок реквизитов стороны для договора | `findById/party` |
| `report --query ... [--out файл]` | карточка контрагента в markdown | `findById/party` |
| `bank --query БИК\|SWIFT\|ИНН\|рег.номер` (`--search` — по названию) | реквизиты банка, корсчёт, статус | `findById/bank`, `suggest/bank` |
| `court --query ... [--type AS\|MS\|RS...] [--code]` | справочник судов: тип, адрес, сайт | `suggest/court`, `findById/court` |
| `tax-office --query ... [--region 77] [--code]` | налоговая инспекция: адрес, реквизиты платежа | `suggest/fns_unit`, `findById/fns_unit` |
| `features` | каталог возможностей DaData, тарифы, что реализовано | — |
| `profile show\|set\|reset` | профиль рабочего пространства (тариф, выбор функций) | — |

Идентификаторы проверяются до запроса: длина и контрольная цифра ИНН/ОГРН (опечатка не тратит суточный лимит;
`--skip-check` отключает). Коды типов судов: `AS` арбитражный суд области, `AA` арбитражный апелляционный, `AO` арбитражный
округа, `AI` по интеллектуальным правам, `VS` Верховный, `OS` областной, `RS` районный, `MS` мировой, `KJ` кассационный
общей юрисдикции, `AJ` апелляционный общей юрисдикции (остальные — военные: `GV`, `AV`, `KV`, `OV`).

## Что приходит на каком тарифе

Бесплатный тариф («Лёгкий» с лимитом 10 000 запросов в сутки) даёт базовые поля; платные поля на нём не включить.
Инструмент определяет тариф по ключу (`auth check`) и в `company`/`report` перечисляет то, что на тарифе недоступно
(`not_in_tariff`), чтобы «данных нет» не путалось с «данные закрыты тарифом».

| Тариф | Дополнительно к базовому |
|---|---|
| Бесплатный / «Лёгкий» | ИНН, КПП, ОГРН и его дата, наименования, ОПФ, адрес, руководитель, статус (действует, ликвидируется, ликвидирована, банкротство, реорганизация) с датами, основной ОКВЭД, коды статистики, число филиалов; банки, суды, налоговые инспекции |
| «Расширенный», 28 000 ₽/год | все ОКВЭД, численность, налоговый режим, налоговая/ПФР/ФСС |
| «Максимальный», 56 000 ₽/год | учредители и доли, руководители, недостоверность сведений (с решением суда), недоимки и штрафы, выручка, лицензии, реестр МСП, контакты, правопредшественники/правопреемники |

Тарифы и цены сверены с dadata.ru 19.10.2026. Покупку тарифа делает только пользователь.

## Условия DaData, которые учтены

- **Хранение.** Права на данные остаются у DaData и правообладателей (оферта, п. 8.1). Ответы кешируются только в
  `.cache/dadata/` (закрыт `.gitignore`), с датой получения; в шаблон, документы-образцы и репозиторий данные не
  переносятся. В материалы дела — только по решению пользователя, с датой получения.
- **Автоматизация.** «Подсказки» нельзя использовать для автоматической обработки (п. 4.2.1): `find` разовый, по просьбе
  пользователя, без циклов; основной путь — точный поиск по ИНН/ОГРН. Одна регистрация на лицо (п. 3.3).
- **Лимиты.** 30 запросов в секунду и 60 новых соединений в минуту с одного IP; 10 000 запросов в сутки на бесплатном тарифе.
  Инструмент держит паузу, повторяет при 429/5xx, считает запросы за сутки (`meta.requests_today`) и предупреждает на
  90 % лимита. 403 означает: ключ неверен, не подтверждена почта либо исчерпан лимит (сброс в 00:00 по Москве).
- **«Как есть» (п. 2.5).** Адрес приходит стандартизованным и может отличаться от ЕГРЮЛ (в `address.as_in_egrul` — как в реестре;
  `check_code` 1 или 3 — проверить вручную). У ИП в адресе только город проживания. Должность руководителя приходит в
  именительном падеже и прописными: падеж и регистр для договора ставит юрист.

## Чего нет у DaData

Дел в арбитражных судах и судах общей юрисдикции, подробностей банкротства (только статус из ЕГРЮЛ; сообщения и процедуры —
Федресурс), исполнительных производств, выписки ЕГРЮЛ на дату. Эти сведения берутся из других источников; список напоминается в
каждой карточке `report` и в `features` (`not_covered_by_dadata`).

## Первое использование

Пока `profile show` даёт `onboarding_done: false`, агент после ответа на первый запрос спрашивает пользователя, какие ещё
возможности DaData подключить, исходя из того, чем занято рабочее пространство (каталог возможностей — `features`: например,
аффилированные компании и учредители для споров о субсидиарной ответственности, склонение ФИО для договоров). Ответ записывается:
`profile set --features id1,id2 --onboarded`. Дополнительные возможности реализуются по запросу пользователя; платные
подключает он сам.

## Коды возврата

`0` успех; `2` неверные параметры (в том числе опечатка в ИНН); `3` ключа нет или DaData его не приняла; `5` лимит или
доступ запрещён; `6` сеть; `7` не найдено. Ошибки — JSON в stderr: `{"error": {"code", "message", "hint"}}`.

## Состав

```
dadata.py                точка входа
dadata_api/cli.py        команды и разбор параметров
dadata_api/http.py       запросы, паузы, повторы, разбор ошибок, кеш
dadata_api/store.py      ключ (secrets/), профиль, счётчик, кеш ответов (.cache/dadata/)
dadata_api/checks.py     проверка ИНН/ОГРН
dadata_api/views.py      приведение ответов к компактному виду, определение тарифа
dadata_api/report.py     карточка контрагента и блок реквизитов
dadata_api/features.py   каталог возможностей и чего DaData не покрывает
```
