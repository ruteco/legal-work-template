# science-search — поиск и загрузка научных материалов

CLI для поиска научных статей, монографий и диссертаций по ключевым словам в открытых научных источниках и
загрузки полных текстов, которые отданы в открытом доступе. Нужен, когда к позиции по делу надо добавить
доктрину: как ту же проблему решают в литературе, какие есть подходы, на какие работы ссылаются суды и коллеги.

Это **вторичные источники**: они не заменяют закон, постановления Пленумов и судебную практику (для них есть
`tools/pravo` и `tools/consultant-api`). Методику работы с найденным (как отбирать, читать, цитировать и
проверять) описывает skill [legal-science-researcher](../../.skills/legal-science-researcher/SKILL.md).

Вывод — JSON в stdout, ошибки — JSON в stderr с кодом возврата. Инструмент сам ничего не пишет в `docs/refs`:
файлы попадают в `.cache/science/` (закрыт `.gitignore`) или в каталог `--out`.

## Требования

- Python 3.9+ и `requests` (`pip install -r tools/science-search/requirements.txt`).
- Для извлечения текста из PDF желателен `pdftotext` (poppler); запасной вариант — `pypdf`, если установлен. Без
  них PDF скачивается, но текст не извлекается (в ответе будет `text_note`).
- Запускать с `python -X utf8` (Windows).
- Ключи и логины не нужны. Необязательные переменные окружения: `SCIENCE_MAILTO` (контакт для «вежливых» очередей
  OpenAlex и Crossref; ставит сам пользователь), `S2_API_KEY` (Semantic Scholar), `CORE_API_KEY` (CORE).

## Быстрый старт

```
# 1. Поиск: несколько формулировок сразу (синонимы, русский и английский), результаты сливаются и ранжируются
python -X utf8 tools/science-search/science.py search --query "исковая давность" --query "срок исковой давности" --from-year 2015

# 2. Скачать открытые тексты из найденного (по умолчанию — все, у кого доступ не закрыт)
python -X utf8 tools/science-search/science.py fetch --search <search_id> --pick open --out <каталог>

# 3. Прочитать извлечённый текст: <каталог>/*.txt (метаданные рядом: *.meta.json)

# 4. То, что скачать нельзя, лежит в <каталог>/manual-downloads.md: показать пользователю.
#    Когда он скачает файл под своей подпиской:
python -X utf8 tools/science-search/science.py ingest --file <файл.pdf> --doi <DOI>
```

## Команды

| Команда | Что делает |
|---|---|
| `sources` | Источники, нужны ли ключи, проверен ли адаптер вживую; что не опрашивается напрямую |
| `search` | Поиск по ключевым словам; результаты разных источников и запросов сливаются, дубли склеиваются по DOI и названию |
| `get --doi` | Метаданные одной работы по DOI (аннотация, ключевые слова, все найденные ссылки на тексты) |
| `fetch` | Скачать полные тексты открытого доступа; остальное — в список «скачать вручную» |
| `ingest` | Подключить PDF, который пользователь скачал вручную: копия, метаданные, извлечённый текст |

### `search`

| Параметр | Назначение |
|---|---|
| `--query` | Ключевые слова; **можно повторять**: каждая формулировка уходит во все источники, результаты объединяются |
| `--lang ru\|en\|any` | Язык работ, по умолчанию `ru` |
| `--from-year`, `--to-year` | Границы по году публикации |
| `--oa-only` | Только работы с открытым доступом |
| `--type` | Тип (повторяемый): `article`, `book`, `book-chapter`, `dissertation`, `preprint`, … (словарь OpenAlex; для Crossref пересчитывается в его типы, DOAJ отдаёт только статьи, OpenAIRE тип не фильтрует) |
| `--sources` | Источники через запятую; по умолчанию `openalex,crossref,doaj,openaire` |
| `--per-source` | Сколько брать у каждого источника на запрос (25) |
| `--limit` | Сколько вернуть после слияния (25) |
| `--sort relevance\|year\|citations` | Порядок. По умолчанию `relevance`: работа, высоко стоящая в нескольких источниках и запросах, поднимается (RRF). `year` и `citations` сортируют после слияния и выносят наверх менее релевантное: брать для уточняющих запросов, а не как основной режим |
| `--abstract-chars` | Длина аннотации в ответе (400; 0 — без аннотаций) |

Ответ: `search_id` (по нему работает `fetch`; результаты лежат в кеше), `sources` (сколько дал каждый источник,
отказы и ошибки по источникам — поиск не падает, если один источник недоступен), `total`, `open_access`, `results[]`
(`n`, `title`, `authors`, `year`, `venue`, `type`, `language`, `doi`, `cited_by`, `access`, `sources`, `abstract`,
`landing_url`, `citation` — библиографическая запись в стиле ГОСТ).

`access`: `open` — открытый доступ подтверждён источником; `closed` — известно, что закрыта; `unknown` — не
известно (может оказаться доступной по ссылке из `get`).

### `fetch`

`--search <id> --pick open|all|1,3,5` и/или `--doi <DOI>` (повторяемый), `--out <каталог>` (по умолчанию
`.cache/science/files`), `--no-text` (не извлекать текст).

Для каждой работы: `<год>_<автор>_<название>_<хеш>.pdf` (или `.txt`), `.txt` с извлечённым текстом и
`.meta.json` (название, авторы, год, журнал, DOI, готовая библиографическая запись, откуда скачано, хеш). Для
скачанного в ответе есть `refs_entry_suggestion` — заготовка записи в `docs/refs.md` (раздел «Научные материалы»).

Если часть работ скачать нельзя, ответ содержит `manual` (причина, ссылки, DOI), `manual_downloads_file`
(`manual-downloads.md` рядом с файлами) и `tell_user` — готовую формулировку для пользователя.

### `ingest`

`--file <PDF>` и, лучше всего, `--doi` (метаданные подтянутся из OpenAlex); иначе `--title`, `--authors` (через
точку с запятой), `--year`, `--venue`. Вручную заданные поля главнее найденных.

## Источники

| Источник | Роль | Статус |
|---|---|---|
| OpenAlex | Основной: язык, год, тип, открытый доступ, цитирования, ссылки на полные тексты (в том числе КиберЛенинка и репозитории) | Проверен вживую |
| Crossref | Библиографические метаданные по DOI; русских журналов мало | Проверен вживую |
| DOAJ | Журналы открытого доступа, в том числе русские; все статьи открыты | Проверен вживую |
| OpenAIRE Graph | Открытые репозитории: диссертации, вузовские архивы | Проверен вживую |
| Semantic Scholar | Англоязычная литература | Проверен; без `S2_API_KEY` частые 429 (источник пропускается) |
| CORE | Тексты из репозиториев | Не проверен: нужен бесплатный `CORE_API_KEY` |

Напрямую не опрашиваются:

- **eLIBRARY.RU (РИНЦ)** — лицензия запрещает автоматический сбор. Статьи оттуда приходят через OpenAlex и
  Crossref (метаданные, DOI); загрузка идёт только руками пользователя под его подпиской (см. ниже).
- **КиберЛенинка** — `robots.txt` закрывает поиск, API и PDF. Ссылки на статьи приходят через OpenAlex; когда PDF
  запрещён, а страница статьи разрешена, текст берётся со страницы статьи.
- Коммерческие библиотеки (Юрайт, Лань, IPR SMART и т. п.), SSRN, HeinOnline, Westlaw, Lexis, Google Scholar —
  только по подписке пользователя, инструмент их не касается.

## Что инструмент скачивает, а что нет

- Качается только то, что источники отдают в открытом доступе **и** что не запрещено `robots.txt` сайта
  (учитываются правила групп `User-agent`, шаблоны `*` и `$`; недоступный `robots.txt` — отказ).
- PDF проверяется по сигнатуре `%PDF-`, размер ограничен 40 МБ; ссылка на страницу вместо файла разбирается: либо
  `citation_pdf_url`, либо текст статьи из блока `itemprop="articleBody"` (не короче 1500 знаков).
- Честный `User-Agent` с названием инструмента, пауза между запросами, повторы при 429/5xx с учётом `Retry-After`.
- Обхода авторизации, капч и платных стен нет и не будет.

### Что делать, когда скачать нельзя

Статья найдена, а скачать её нельзя (eLIBRARY, закрытый доступ, запрет `robots.txt`, нет ссылки): **сообщить
об этом пользователю** (см. `tell_user` и `manual-downloads.md` — там библиографическая запись, причина и ссылки),
чтобы он скачал под своей подпиской и положил PDF в рабочую папку. Затем подключить командой `ingest`. До этого
работа считается известной только по метаданным и аннотации — выводы о её содержании делать нельзя.

## Ограничения

- Язык работ определяется по метке источника, а если её нет или она ненадёжна — по алфавиту заголовка.
- Покрытие российских журналов в OpenAlex и Crossref неполное; полная картина по РИНЦ доступна только в самом
  eLIBRARY. Отсутствие работы в выдаче не означает, что её нет.
- Число цитирований (`cited_by`) берётся из OpenAlex и для российской литературы занижено; это ориентир, а не
  оценка качества.
- Аннотации в выдаче могут быть обрезаны или быть рекламой журнала; читать нужно полный текст.
- Текст из PDF без текстового слоя (сканы) не извлекается.

## Коды возврата

`0` успех; `2` неверные параметры; `6` сетевая ошибка; `7` не найдено; `1` внутренняя ошибка. Ошибка печатается
в stderr как `{"error": {"code", "message", "hint"}}`.

## Структура

```
tools/science-search/
  science.py            точка входа
  requirements.txt
  science_search/
    cli.py              команды и параметры
    sources.py          адаптеры источников и реестр
    model.py            модель работы, слияние, дедупликация, ранжирование, библиографическая запись
    fetch.py            загрузка, извлечение текста, список «скачать вручную», ingest
    http.py             запросы: User-Agent, паузы, повторы
    robots.py           разбор robots.txt (RFC 9309)
    paths.py, errors.py
```
