# tools/ — вспомогательные инструменты

Инструменты двух видов:

- **Поиск первоисточников** (`pravo`, `consultant-browser`, `garant`) — скрипты
  для поиска и загрузки НПА, кодексов, законов и судебной практики из внешних
  правовых систем. Дополняют обычный веб-поиск, когда нужен структурированный
  доступ (поиск по реквизитам, метаданные, прямое скачивание файла) — см.
  правило работы с первоисточниками в [AGENTS.md](AGENTS.md).
- **Подготовка документов** (`docx-export`) — выгрузка готовых материалов в
  форматы, в которых их ждёт клиент или суд.

Ни один из инструментов поиска не пишет в `docs/refs` автоматически: сохранение
первоисточника локально всегда требует подтверждения пользователя, это
делает вызывающий агент отдельным шагом после ответа пользователя.

# Поиск первоисточников

## [tools/pravo](tools/pravo/README.md) — publication.pravo.gov.ru

**Статус: рабочий, проверен вживую.** Официальный открытый API "Официального
интернет-портала правовой информации" (раздел "Официальное опубликование").
Авторизация не нужна. Позволяет искать документы по реквизитам (номер, дата,
принявший орган, вид документа, текст) и скачивать сами файлы (PDF) напрямую.
Приоритетный источник для загрузки первоисточников — это официальная
публикация в аутентичном виде.

Подробности и примеры — [tools/pravo/README.md](tools/pravo/README.md),
спецификация эндпоинтов — [tools/pravo/docs/api-spec-summary.md](tools/pravo/docs/api-spec-summary.md).

## [tools/garant](tools/garant/README.md) — API системы ГАРАНТ

**Статус: черновик, не работает.** Официальный API компании "Гарант"
("Гарант Коннект") — коммерческий, доступ только по договору вместе с
подпиской на систему ГАРАНТ (не куплена). Код написан по официальной
спецификации (методы, JSON-схемы, лимиты) и синтаксически исправен, но ни
разу не вызывался против реального сервера — нет токена доступа. Даёт более
широкие возможности, чем pravo.gov.ru (свежая консолидированная редакция,
язык запросов, снипеты, мониторинг изменений, лента новостей ПРАЙМ), когда/если
появится доступ.

Подробности — [tools/garant/README.md](tools/garant/README.md), спецификация
эндпоинтов — [tools/garant/docs/api-spec-summary.md](tools/garant/docs/api-spec-summary.md).

## [tools/consultant-browser](tools/consultant-browser/README.md) — КонсультантБраузер (cloud.consultant.ru)

**Статус: рабочий, проверен вживую.** Не API, а работа через браузерный
инструмент в личном кабинете КонсультантПлюс пользователя (открытого API у
КонсультантПлюс нет). Пользователь сам логинится (агенту запрещено вводить
пароли), дальше агент ищет и читает документы в уже авторизованной сессии —
"Карточка поиска", вкладки "Законодательство"/"Судебная практика",
классификаторы вроде "Принявший орган". Покрывает то, чего нет в открытых
источниках: судебную практику (включая КС РФ, ВС РФ, арбитражные суды),
аналитику, кодексы с комментариями — в пределах подписки пользователя.

Подробности, включая технические особенности автоматизации (клики по `ref`,
а не по координатам; полный текст документа — во вложенном iframe;
неустойчивость "ручных" URL с токенами сессии) — 
[tools/consultant-browser/README.md](tools/consultant-browser/README.md).

## Общий принцип поиска первоисточника

1. Сначала проверить локальный кеш — [docs/refs.md](docs/refs.md) и каталог
   `docs/refs` (см. AGENTS.md).
2. Если нужного документа нет локально — искать через `tools/pravo` (рабочий,
   официальный, без ограничений доступа) — приоритетно для НПА/законов.
3. Если нужны судебная практика, аналитика или другие материалы за пределами
   pravo.gov.ru — использовать `tools/consultant-browser` (требует, чтобы
   пользователь уже авторизовался в личном кабинете КонсультантПлюс в
   Browser pane).
4. `tools/garant` — резерв на случай, если появится оплаченный доступ и
   понадобятся его дополнительные возможности (актуальная редакция с учётом
   правок, язык запросов, мониторинг изменений).

# Подготовка документов

## [tools/docx-export](tools/docx-export/README.md) — выгрузка в Word (.docx)

**Статус: рабочий, проверен вживую.** Скрипт `md2docx.py` конвертирует Markdown
в `.docx` с оформлением под российские юридические документы: А4, Times New
Roman 14 пт, поля 30/15/20/20 мм, полуторный интервал, абзацный отступ 12,5 мм,
выключка по ширине. Позволяет держать текст документа в Markdown (удобно
править, видно в diff), а Word получать одной командой.

```
python3 tools/docx-export/md2docx.py вход.md [выход.docx] [опции]
```

Поддерживает шапку процессуального документа, заголовки, вложенные списки,
таблицы, разрывы страниц, блоки по центру и по правому краю (для даты и
подписи), полужирный/курсив/моноширинный текст. Подчёркивания как разметка
намеренно не поддерживаются — иначе съедались бы строки для заполнения вида
`«___» _______ 2026 г.`

Подробности, полный перечень разметки и опций —
[tools/docx-export/README.md](tools/docx-export/README.md).
