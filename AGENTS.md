# AGENTS.md

Правила работы агента в этом проекте.

## Назначение workspace

Этот каталог — рабочий каталог Юриста. Здесь ведётся работа с документами: поиск, анализ, подготовка и хранение материалов по юридическим задачам.

## Структура каталога

- **docs/** — документы.
  - **docs/refs/** — локальное хранилище первоисточников: федеральные законы, кодексы, нормативные акты и т.п.
  - **docs/refs.md** — реестр первоисточников, загруженных в `docs/refs`: название документа, суть/описание и ссылка на загруженный файл.
- **worklogs/** — рабочие журналы.
  - **worklogs/plan.md** — краткосрочный план выполнения текущей задачи.
  - **worklogs/recent.md** — журнал завершённых задач. По завершении задачи запись добавляется в **начало** файла в формате: `дата — суть задачи и что было сделано`.

## Правила работы с первоисточниками

- Перед поиском первоисточников для задачи сначала проверяй `docs/refs.md` и каталог `docs/refs` — это локальный кеш ранее загруженных документов. Если нужный первоисточник уже есть локально, использовать его вместо повторного поиска.
- Если первоисточник найден во внешнем источнике и его ещё нет в локальном кеше, нужно спросить пользователя, сохранить ли его локально в `docs/refs`. При сохранении — добавить запись в `docs/refs.md`.

## Правила работы с worklogs

- В начале работы над задачей записывай краткосрочный план в `worklogs/plan.md`.
- По завершении задачи добавляй запись в начало `worklogs/recent.md` с датой, сутью задачи и кратким описанием того, что было сделано.

## Выбор роли (skill)

Для каждого запроса пользователя необходимо выбрать подходящую роль (skill) из директории [.skills](./.skills).

- При активации skill нужно явно обозначить, с каким skill производится действие (указать его имя перед выполнением запроса).
- Если подходящего skill в директории нет, действовать без него, но сообщить об этом.

## Список skills

Пока директория `.skills` пуста. По мере добавления новых skill они будут перечислены здесь.
