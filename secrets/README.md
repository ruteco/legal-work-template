# secrets/

Каталог для секретов инструментов (куки сессий и т.п.). **Его содержимое никогда не попадает в репозиторий**:
`.gitignore` в этом каталоге пропускает только `.gitignore` и этот файл.

- Что хранится: сессия КонсультантПлюс (`consultant-session.json`: куки и служебный `rnd`) и API-ключ DaData
  (`dadata.json`). Логин и пароль не сохраняются нигде.
- Как появляются: сессию КонсультантПлюс инструмент создаёт сам после `auth login`, который пользователь запускает в своём
  терминале. API-ключ пользователь передаёт агенту или вводит сам, сохраняет его команда `auth set` инструмента
  `tools/dadata` (агент передаёт ключ через стандартный ввод и дальше его не повторяет).
- Правила: не читать, не печатать, не копировать в документы и переписку, не коммитить; при утечке сессии выйти из
  КонсультантПлюс (истечёт сама через 30 минут простоя) и выполнить `auth forget`; при утечке ключа DaData сообщить пользователю:
  ключ нужно заменить в личном кабинете dadata.ru (или через поддержку), затем выполнить `auth forget` и `auth set`.
- Новые инструменты хранят секреты тоже здесь и описывают это в своём README.
