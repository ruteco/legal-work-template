# secrets/

Каталог для секретов инструментов (куки сессий и т.п.). **Его содержимое никогда не попадает в репозиторий**:
`.gitignore` в этом каталоге пропускает только `.gitignore` и этот файл.

- Что хранится: сессия КонсультантПлюс (`consultant-session.json`: куки и служебный `rnd`). Логин и пароль
  не сохраняются нигде.
- Как появляются: инструмент создаёт файл сам после `auth login`, который пользователь запускает в своём терминале.
- Правила: не читать, не печатать, не копировать в документы и переписку, не коммитить; при утечке сессии выйти из
  КонсультантПлюс (истечёт сама через 30 минут простоя) и выполнить `auth forget`.
- Новые инструменты хранят секреты тоже здесь и описывают это в своём README.
