# Первоисточники (refs)

Реестр загруженных первоисточников (федеральные законы, кодексы, нормативные акты и т.п.), сохранённых локально в каталоге [refs](./refs).

Формат записи:

## Название документа

- **Суть/описание:** краткое описание документа и его значения для работы.
- **Файл:** [refs/имя-файла.ext](./refs/имя-файла.ext)
